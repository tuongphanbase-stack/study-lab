Fast Exponentiation

Computing base^exponent the naive way takes exponent-many multiplications. Exponentiation by squaring does it in log(exponent) steps by walking the exponent's binary digits.

How it works

Computing base^exponent the obvious way means multiplying base by itself, over and over, exponent times. For small exponents that's fine, but for huge ones (cryptography routinely uses exponents hundreds of digits long) it's far too slow.

Exponentiation by squaring is a much faster way to get the same answer:

  1. Look at the exponent's binary digits, one at a time.
  2. Keep a running "squared base" value, and square it again after every digit.
  3. Whenever a digit is 1, multiply that squared value into the answer. Whenever it's 0, skip it.

Since the exponent's binary form only has about log(exponent) digits, this only takes that many steps — dramatically fewer than multiplying one at a time.

Example

Computing 3^5: 5 in binary is 101. Starting with result 1 and base 3 — bit 1 (rightmost): multiply in, result becomes 3, square the base to 9. Bit 0: skip, square the base to 81. Bit 1: multiply in, result becomes 3 × 81 = 243 — matching 3^5 = 243, using only 3 multiplications instead of 5.

function power(base, exp):
    result <- 1
    while exp > 0:
        if exp is odd:                    // this bit of the exponent is 1
            result <- result * base         // fold the current squared base into the answer
        base <- base * base                // square the base for the next bit position
        exp <- exp / 2                     // move to the next bit (integer division)
    return result

# Python's built-in pow(base, exp) already does this internally
function power(base, exp) {
  let result = 1n;            // BigInt, so results stay exact for large exponents
  base = BigInt(base);

  while (exp > 0) {
    if (exp % 2 === 1) {        // this bit of the exponent is 1
      result *= base;             // fold the current squared base into the answer
    }
    base *= base;                // square the base for the next bit position
    exp = Math.floor(exp / 2);   // move to the next bit (integer division)
  }

  return result;
}
