Bitwise-ops

Click any bit to flip it, pick an operation, and watch the result form one bit at a time — the same logic your CPU runs on every integer, just at 8-bit scale.

How it works

A number stored in binary is just a row of 0s and 1s. Each column is worth double the one to its right — 128, 64, 32, 16, 8, 4, 2, 1 for 8 bits. Every operation below works one column at a time, comparing only the two bits directly above each other.

  • AND — the result bit is 1 only when both input bits are 1. Useful for clearing specific bits while keeping the rest.
  • OR — the result bit is 1 when either input bit is 1. Useful for turning specific bits on.
  • XOR — the result bit is 1 when the two input bits are different. Useful for flipping bits, or spotting what changed between two values.
  • NOT — flips every bit: 0 becomes 1, and 1 becomes 0.
  • << and >> — shift every bit one spot left or right. Shifting left doubles the number; shifting right cuts it in half.
Example

5 is 0101 in binary, 3 is 0011. Column by column: 0&0=0, 1&0=0, 0&1=0, 1&1=1. So 5 AND 3 = 0001, which is 1 — only the last column had a 1 in both numbers.

Code
AND(a, b): result bit is 1 only if both bits are 1     // masks: keeps shared bits
OR(a, b):  result bit is 1 if either bit is 1                // combines: turns bits on
XOR(a, b): result bit is 1 if the bits differ                // toggles: flips differing bits
NOT(a):    flips every bit                                    // 0 becomes 1, 1 becomes 0
a << n:    shift bits left by n   (multiplies by 2^n)         // fills new low bits with 0
a >> n:    shift bits right by n  (divides by 2^n)            // discards the low bits shifted out
a, b = 0b11001011, 0b01011010   # two 8-bit values written in binary

a & b        # AND -> masks: keep only bits set in both a and b
a | b        # OR  -> combine: set bits present in either a or b
a ^ b        # XOR -> toggle: set bits where a and b differ
~a           # NOT -> flips every bit (Python ints are infinite-width,
             #        so this looks different from a fixed 8-bit flip)
a << 1       # shift left  -> multiply by 2, a 0 fills the new low bit
a >> 1       # shift right -> divide by 2 (integer division), low bit is discarded
const a = 0b11001011, b = 0b01011010;   // two 8-bit values written in binary

a & b;        // AND -> masks: keep only bits set in both a and b
a | b;        // OR  -> combine: set bits present in either a or b
a ^ b;        // XOR -> toggle: set bits where a and b differ
~a & 0xFF;    // NOT -> flip every bit, masked to 8 bits so it displays cleanly
a << 1;       // shift left  -> multiply by 2, a 0 fills the new low bit
a >> 1;       // shift right -> divide by 2 (integer division), low bit is discarded
