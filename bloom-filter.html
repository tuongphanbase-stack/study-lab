Bloom Filter

A fixed-size bit array that answers "have I seen this key before?" without storing any keys at all. Insert a few, then check one — watch how false positives can sneak in.

How it works

A Bloom filter answers one question cheaply: "have I possibly seen this key before?" It doesn't store the actual keys — just a row of bits — which is what makes it so small and fast. The tradeoff: it can say "definitely no," but it can only ever say "maybe yes."

Inserting a key runs it through a few different hash functions. Each one points to a bit position, and all of those bits get flipped on.

Checking a key runs it through the same hash functions and looks at those same bit positions.

  • If any of those bits are off, the key was definitely never inserted.
  • If all of those bits are on, the key is probably present — but it's also possible those bits just happened to get turned on by other keys. That's called a false positive.

The more keys you insert, the more bits get turned on, and the more likely a false positive becomes. That's the core tradeoff of a Bloom filter: save space, but accept a small chance of being wrong in one direction.

Example

Inserting "cat" might flip bits 2, 5, and 9 on. Checking "dog" hashes to bits 2, 5, and 7 — bit 7 is off, so the filter correctly says "dog" was definitely never inserted. Checking "cat" again hashes to the same bits 2, 5, 9, all of which are on — so it reports "cat" as probably present.

function insert(bits, key):
    for each hashFunction in [h1, h2, h3]:      // run the key through every hash function
        index <- hashFunction(key) mod size(bits)
        bits[index] <- 1                          // flip that bit on

function mightContain(bits, key):
    for each hashFunction in [h1, h2, h3]:      // check every bit the key would have set
        index <- hashFunction(key) mod size(bits)
        if bits[index] == 0:
            return false                           // this bit is off: key was never inserted
    return true  // every relevant bit is on: maybe present (could be a false positive)
class BloomFilter:
    def __init__(self, size=24):
        self.size = size
        self.bits = [0] * size   # start with every bit off

    def _hashes(self, key):
        # three independent-ish hash functions over the same key
        h1 = sum((i+1) * ord(c) for i, c in enumerate(key)) % self.size
        h2 = sum((i*3+7) * ord(c) for i, c in enumerate(key)) % self.size
        h3 = sum((i*5+13) * ord(c) for i, c in enumerate(key)) % self.size
        return [h1, h2, h3]

    def insert(self, key):
        for index in self._hashes(key):
            self.bits[index] = 1   # flip each of this key's three bits on

    def might_contain(self, key):
        return all(self.bits[index] for index in self._hashes(key))
        # True only if every one of the key's three bits is already on
class BloomFilter {
  constructor(size = 24) {
    this.size = size;
    this.bits = new Array(size).fill(0);   // start with every bit off
  }

  hashes(key) {
    // three independent-ish hash functions over the same key
    let h1 = 0, h2 = 7, h3 = 13;
    for (const c of key) {
      h1 = (h1 * 31 + c.charCodeAt(0)) % this.size;
      h2 = (h2 * 17 + c.charCodeAt(0) * 3) % this.size;
      h3 = (h3 * 23 + c.charCodeAt(0) * 7 + 11) % this.size;
    }
    return [h1, h2, h3];
  }

  insert(key) {
    for (const index of this.hashes(key)) this.bits[index] = 1;   // flip each bit on
  }

  mightContain(key) {
    return this.hashes(key).every(index => this.bits[index] === 1);
    // true only if every one of the key's three bits is already on
  }
}
class BloomFilter {
    boolean[] bits;
    int size;

    BloomFilter(int size) {
        this.size = size;
        bits = new boolean[size];   // starts with every bit false (off)
    }

    int[] hashes(String key) {
        // three independent-ish hash functions over the same key
        int h1 = 0, h2 = 7, h3 = 13;
        for (char c : key.toCharArray()) {
            h1 = (h1 * 31 + c) % size;
            h2 = (h2 * 17 + c * 3) % size;
            h3 = (h3 * 23 + c * 7 + 11) % size;
        }
        return new int[]{h1, h2, h3};
    }

    void insert(String key) {
        for (int index : hashes(key)) bits[index] = true;   // flip each bit on
    }

    boolean mightContain(String key) {
        for (int index : hashes(key)) {
            if (!bits[index]) return false;   // this bit is off: definitely never inserted
        }
        return true;   // every relevant bit is on: maybe present
    }
}
