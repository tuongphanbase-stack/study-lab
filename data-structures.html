Data-structures

The same handful of operations, four different shapes. Push a stack, enqueue a queue, insert into a linked list, or drop a value into a binary search tree.

How it works

  • Stack (LIFO) — imagine a stack of plates. You can only add or remove from the top. push adds a new plate, pop removes the top one. A program's call stack works exactly this way (see the recursion page).
  • Queue (FIFO) — imagine a checkout line. People join at the back and leave from the front. enqueue adds to the back, dequeue removes from the front. This is exactly what BFS uses to explore in order.
  • Linked list — instead of one big block of memory like an array, each item ("node") just points to the next one. Adding or removing at either end is fast, since nothing needs to shift over. The tradeoff: to reach item 5, you have to walk through items 1 through 4 first.
  • Binary search tree — every node follows one rule: smaller values go left, larger values go right. To insert a value, start at the top and keep going left or right based on that rule, until you find an empty spot. On a balanced tree, this takes about log(n) steps.
Example

Stack: push 1, then 2, then 3. Calling pop returns 3 first — the last thing added comes off first.

Queue: enqueue 1, then 2, then 3. Calling dequeue returns 1 first — the first thing added comes off first.

BST: insert 5, then 3, then 8. 3 is smaller than 5 so it becomes the left child; 8 is larger so it becomes the right child.

// Stack (LIFO) - only the top is ever touched
push(stack, value): stack.append(value)      // add to the top
pop(stack): return stack.removeLast()         // remove from the top

// Queue (FIFO) - added at the back, removed from the front
enqueue(queue, value): queue.append(value)    // add to the back
dequeue(queue): return queue.removeFirst()     // remove from the front

// Binary search tree insert - keeps left < node < right everywhere
function insert(node, value):
    if node is null: return newNode(value)         // found an empty spot: place it here
    if value < node.value: node.left <- insert(node.left, value)    // go left if smaller
    else: node.right <- insert(node.right, value)                    // go right otherwise
    return node                                     // return node so the parent link updates
# Stack (LIFO) - Python lists work directly, both ends O(1) amortized
stack = []
stack.append(7)   # push: add to the top
stack.pop()        # pop: remove from the top

# Queue (FIFO) - use deque for O(1) on both ends (lists are O(n) at the front)
from collections import deque
queue = deque()
queue.append(7)     # enqueue: add to the back
queue.popleft()      # dequeue: remove from the front

# Binary search tree insert
class Node:
    def __init__(self, value):
        self.value = value   # the stored value
        self.left = None      # subtree of smaller values
        self.right = None     # subtree of larger (or equal) values

def insert(node, value):
    if node is None:
        return Node(value)          # found an empty spot: place the new node here
    if value < node.value:
        node.left = insert(node.left, value)    # smaller: recurse into the left subtree
    else:
        node.right = insert(node.right, value)  # otherwise: recurse into the right subtree
    return node   # hand back the (possibly updated) subtree to the caller
// Stack (LIFO) - arrays work directly, both ends O(1)
const stack = [];
stack.push(7);   // push: add to the top
stack.pop();      // pop: remove from the top

// Queue (FIFO) - shift() is O(n) here; a linked list gives true O(1) dequeue
const queue = [];
queue.push(7);    // enqueue: add to the back
queue.shift();     // dequeue: remove from the front

// Binary search tree insert
class Node {
  constructor(value) {
    this.value = value;   // the stored value
    this.left = null;      // subtree of smaller values
    this.right = null;     // subtree of larger (or equal) values
  }
}

function insert(node, value) {
  if (!node) return new Node(value);   // found an empty spot: place the new node here
  if (value < node.value) node.left = insert(node.left, value);   // smaller: go left
  else node.right = insert(node.right, value);                     // otherwise: go right
  return node;   // hand back the (possibly updated) subtree to the caller
}

class Node {
    int value;         // the stored value
    Node left, right;  // subtrees of smaller / larger-or-equal values
    Node(int value) { this.value = value; }
}

static Node insert(Node node, int value) {
    if (node == null) return new Node(value);   // found an empty spot: place it here
    if (value < node.value) node.left = insert(node.left, value);   // smaller: go left
    else node.right = insert(node.right, value);                     // otherwise: go right
    return node;   // hand back the (possibly updated) subtree to the caller
}

struct Node {
    int value;                     // the stored value
    Node* left = nullptr;          // subtree of smaller values
    Node* right = nullptr;         // subtree of larger (or equal) values
    Node(int v) : value(v) {}
};

Node* insert(Node* node, int value) {
    if (!node) return new Node(value);   // found an empty spot: place it here
    if (value < node->value) node->left = insert(node->left, value);   // smaller: go left
    else node->right = insert(node->right, value);                      // otherwise: go right
    return node;   // hand back the (possibly updated) subtree to the caller
}
