Dynamic-programming

DP solves a big problem by filling in a table of smaller subproblems once each, then reusing those answers instead of recomputing them. Watch the table fill in, cell by cell.

How it works

Dynamic programming (DP) is useful when a problem breaks down into smaller versions of itself, and those smaller versions repeat. Instead of solving the same smaller problem over and over (like plain recursion does), DP solves each one exactly once and saves the answer in a table for later.

Fibonacci: each cell is just the sum of the two cells before it — dp[i] = dp[i-1] + dp[i-2]. Fill the table left to right, starting from two known base values.

0/1 knapsack: each cell dp[i][c] answers "what's the best value I can get, using only the first i items, with c capacity left?" For each item, there are two choices: skip it, or take it if it fits. The cell stores whichever choice gives the better result.

Edit distance: each cell asks "how many single-letter changes turn one prefix into the other?" If the current letters already match, no extra work is needed — just copy the answer from the diagonal cell. Otherwise, add one edit to whichever neighboring cell is cheapest.

In every case, the table only needs to be filled once, and each cell only depends on cells that were already computed earlier.

Example

Knapsack example: capacity 5, one item weighs 3 and is worth 4, another weighs 2 and is worth 3. Taking both fits exactly (3 + 2 = 5) for a total value of 4 + 3 = 7 — better than taking just one item alone.

Fibonacci example: dp[5] = dp[4] + dp[3] = 3 + 2 = 5, filled in directly from two already-known cells.

function knapsack(weights[], values[], capacity):
    n <- length(weights)
    dp <- table of size (n+1) x (capacity+1), filled with 0   // dp[i][c] = best value

    for i from 1 to n:                       // consider items one at a time
        for c from 0 to capacity:             // for every possible capacity so far
            dp[i][c] <- dp[i-1][c]              // option 1: skip item i, carry forward
            if weights[i-1] <= c:                // item i actually fits in capacity c
                dp[i][c] <- max(dp[i][c], dp[i-1][c-weights[i-1]] + values[i-1])
                // option 2: take item i, add its value to the best value with less capacity

    return dp[n][capacity]   // best value achievable using all items within the capacity

function knapsack(weights, values, capacity) {
  const n = weights.length;
  const dp = Array.from({ length: n + 1 }, () => new Array(capacity + 1).fill(0));
  // dp[i][c] = best value achievable using the first i items with capacity c

  for (let i = 1; i <= n; i++) {          // consider items one at a time
    for (let c = 0; c <= capacity; c++) {  // for every possible capacity so far
      dp[i][c] = dp[i - 1][c];              // option 1: skip item i, carry forward
      if (weights[i - 1] <= c) {             // item i actually fits in capacity c
        dp[i][c] = Math.max(dp[i][c], dp[i - 1][c - weights[i - 1]] + values[i - 1]);
        // option 2: take item i, add its value to the best value with less capacity
      }
    }
  }

  return dp[n][capacity]; // best value achievable using all items within the capacity
}
