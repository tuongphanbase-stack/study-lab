Finite State Machine

A turnstile has exactly two states and two possible inputs. Feed it coins and pushes and watch it transition — the same states-plus-rules model that powers the regex engine on this site.

How it works

A finite state machine is just two things: a set of states, and a table of rules saying "if I'm in state X and input Y happens, move to state Z." At any moment, the machine is sitting in exactly one state — nothing more is remembered.

This page simulates a turnstile with two states, locked and unlocked, and two possible inputs, coin and push:

  • Insert a coin into a locked turnstile → it unlocks.
  • Push an unlocked turnstile → it locks again.
  • Insert a coin into an already-unlocked turnstile → nothing changes.
  • Push a locked turnstile → nothing changes, it stays locked.

This exact idea — states plus a rule table — is also what powers the regex engine on this site. A pattern gets turned into a state machine, and matching a string just means feeding it in one character at a time.

Example

Starting locked: insert a coin → state becomes unlocked. push → state becomes locked again. Try to push a locked turnstile → nothing happens, it's still locked. Every transition only depends on the current state and the input — nothing from further back is remembered.

current state: locked
Code
transitions <- {
    (locked, coin): unlocked,     // inserting a coin unlocks it
    (locked, push): locked,       // pushing a locked turnstile does nothing
    (unlocked, coin): unlocked,   // a second coin doesn't change anything
    (unlocked, push): locked      // pushing an unlocked turnstile locks it again
}

state <- locked                  // every turnstile starts locked

function feed(input):
    state <- transitions[(state, input)]   // look up the one valid next state
transitions = {
    ("locked", "coin"): "unlocked",    # inserting a coin unlocks it
    ("locked", "push"): "locked",      # pushing a locked turnstile does nothing
    ("unlocked", "coin"): "unlocked",  # a second coin doesn't change anything
    ("unlocked", "push"): "locked",    # pushing an unlocked turnstile locks it again
}

state = "locked"   # every turnstile starts locked

def feed(input_symbol):
    global state
    state = transitions[(state, input_symbol)]   # look up the one valid next state

feed("coin")   # state becomes "unlocked"
feed("push")   # state becomes "locked"
