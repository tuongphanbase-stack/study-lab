Pathfinding

Drag to draw walls, then race BFS, DFS, Dijkstra, or A* from the green cell to the red one. Tinted cells were explored; the solid indigo trail is the final path.

How it works

All four algorithms do the same basic thing: start at the green cell, and spread out to nearby cells one step at a time until they reach the red cell. The difference is which cell each one picks next.

  • BFS always explores the closest unexplored cells first. Think of it like ripples spreading out from a stone dropped in water. Because of this, the very first time it reaches the end, that route is guaranteed to be the shortest one.
  • DFS picks one direction and follows it as far as it can go, only turning back when it hits a dead end. It will find a path, but not necessarily the shortest one.
  • Dijkstra is built for grids where some steps cost more than others. At each step, it always continues from whichever reachable cell has the cheapest total cost so far.
  • A* works like Dijkstra, but it also guesses how far each cell is from the goal in a straight line. That guess nudges the search to head toward the goal instead of spreading out evenly in every direction.

Walls are simple: they're just cells the algorithm is never allowed to step into.

Example

Picture a 4×4 grid with a wall down the middle, leaving one gap. Starting from the top-left corner, BFS checks all cells 1 step away first, then all cells 2 steps away, and so on — like ripples spreading outward. It reaches the gap in the wall, spreads through it, and reaches the bottom-right corner in exactly 6 steps. Since BFS always finishes the closer cells before the farther ones, that 6-step route is guaranteed to be the shortest one possible.

function BFS(grid, start, end):
    queue <- [start]              // cells waiting to be explored, oldest first
    visited <- {start}            // cells we've already queued, so we don't requeue them
    parent <- {}                  // remembers how we reached each cell, for path rebuilding

    while queue is not empty:                    // keep going until nothing left to explore
        node <- queue.dequeue()                   // take the oldest queued cell
        if node == end:                           // reached the destination
            return reconstructPath(parent, end)    // walk parent pointers back to start

        for neighbor in neighbors(node):                     // check every adjacent cell
            if neighbor not in visited and neighbor is not a wall:
                visited.add(neighbor)                          // mark so we never requeue it
                parent[neighbor] <- node                       // remember how we got here
                queue.enqueue(neighbor)                        // schedule it for exploration

    return "no path found"        // queue emptied without reaching the end

def bfs(grid, start, end):
    queue = deque([start])          # cells waiting to be explored, oldest first
    visited = {start}               # cells already queued, so we don't requeue them
    parent = {}                     # maps a cell to the cell we reached it from

    while queue:                              # keep going until nothing left to explore
        node = queue.popleft()                 # take the oldest queued cell, O(1)
        if node == end:                        # reached the destination
            return reconstruct_path(parent, end)

        for neighbor in neighbors(grid, node): # check every adjacent, non-wall cell
            if neighbor not in visited:
                visited.add(neighbor)           # mark so it's never queued twice
                parent[neighbor] = node         # remember how we got here
                queue.append(neighbor)          # schedule it for exploration

    return None  # queue emptied without reaching the end

def reconstruct_path(parent, end):
    path = [end]                    # start from the destination and work backwards
    while path[-1] in parent:       # keep walking until we hit the start (no parent)
        path.append(parent[path[-1]])
    path.reverse()                  # we built it backwards, so flip it
    return path
function bfs(grid, start, end) {
  const queue = [start];                    // cells waiting to be explored, oldest first
  const visited = new Set([key(start)]);    // stringified coords already queued
  const parent = new Map();                 // cell -> the cell we reached it from

  while (queue.length) {                    // keep going until nothing left to explore
    const node = queue.shift();              // take the oldest queued cell
    if (node.r === end.r && node.c === end.c) { // reached the destination
      return reconstructPath(parent, end);
    }

    for (const neighbor of neighbors(grid, node)) { // check every adjacent, non-wall cell
      const k = key(neighbor);
      if (!visited.has(k)) {
        visited.add(k);                      // mark so it's never queued twice
        parent.set(k, node);                  // remember how we got here
        queue.push(neighbor);                 // schedule it for exploration
      }
    }
  }
  return null; // queue emptied without reaching the end
}
