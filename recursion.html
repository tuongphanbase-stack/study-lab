Recursion

Recursion is a function calling itself, with a stack quietly keeping track of every unfinished call. Watch the stack for fibonacci, and watch backtracking undo bad guesses in N-Queens.

How it works

A recursive function calls itself to solve a smaller version of the same problem. It always needs two parts:

  • A base case — a simple version it can answer directly, with no further calls. Here, fib(0) and fib(1) just return right away.
  • A recursive case — it calls itself on a smaller input. fib(n) calls fib(n-1) and fib(n-2), and adds the results.

Every time a call starts, it gets added to the call stack — that's the "call stack (live)" panel below. It stays there until it gets an answer back from its own recursive calls, then it's removed. This is why the tree grows outward first, before collapsing back into a final answer.

One problem with this simple version: it repeats work. fib(3) gets calculated separately inside both fib(4) and fib(5). The dynamic-programming page fixes exactly this.

N-Queens uses a different recursive trick called backtracking: place a queen, then try to place the next one. If you ever get stuck with no valid spot, undo the last placement and try a different column instead. It's trial and error, but it gives up on bad attempts early instead of checking every possibility to the end.

Example

fib(4) calls fib(3) and fib(2). fib(3) then calls fib(2) and fib(1) — notice fib(2) gets computed twice, once inside fib(4)'s call and once inside fib(3)'s call. That repeated work is exactly what the dynamic-programming page avoids.

For N-Queens on a 4×4 board: place a queen at row 0, column 0. Row 1's only safe spot turns out to conflict with later rows, so the algorithm backtracks all the way to row 0, tries column 1 instead, and continues from there.

function fib(n):
    if n <= 1: return n              // base case: fib(0)=0, fib(1)=1, nothing to compute
    return fib(n - 1) + fib(n - 2)   // recursive case: sum of the two prior values

            cols[row] <- col              // place the queen here
            if solveNQueens(row + 1, cols):  // recurse into the next row
                return true                   // downstream succeeded, bubble success up
            cols[row] <- -1               // backtrack: undo the placement, try next column
    return false                       // no column in this row worked

def solve_n_queens(row, cols, n):
    if row == n:
        return True   # every row has a queen placed: solution found

    for col in range(n):              # try each column in this row
        if is_safe(row, col, cols):    # no earlier queen attacks this square
            cols[row] = col              # place the queen here
            if solve_n_queens(row + 1, cols, n):  # recurse into the next row
                return True                          # success! bubble it back up
            cols[row] = -1               # backtrack: undo the placement, try next column

    return False   # no column in this row led to a solution

def is_safe(row, col, cols):
    for r in range(row):                                    # check every earlier row
        if cols[r] == col or abs(cols[r] - col) == row - r:  # same column or same diagonal
            return False
    return True

function solveNQueens(row, cols, n) {
  if (row === n) return true;   // every row has a queen placed: solution found

  for (let col = 0; col < n; col++) {   // try each column in this row
    if (isSafe(row, col, cols)) {        // no earlier queen attacks this square
      cols[row] = col;                    // place the queen here
      if (solveNQueens(row + 1, cols, n)) return true; // recurse; success bubbles up
      cols[row] = -1;                     // backtrack: undo, try the next column
    }
  }
  return false;   // no column in this row led to a solution
}
