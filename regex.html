Regex-engine

A simplified engine supporting literals, . (any char), * (zero or more of the previous token), and + (one or more). Watch it try to match the pattern against the string, position by position.

How it works

The pattern is broken into small pieces called tokens — each one is either a literal character, a . (matches anything), or a character followed by */+. The engine walks through the tokens left to right, comparing each one to the string.

The tricky part is * and +, since "zero or more" or "one or more" doesn't say exactly how many characters to grab. This engine solves it with a strategy called greedy backtracking:

  1. Grab as many matching characters as possible.
  2. Try to match the rest of the pattern against what's left.
  3. If that fails, give back one character and try again.
  4. Keep giving back characters until it works, or there's nothing left to give back.

The pattern also isn't locked to the start of the string. If it doesn't match starting at position 0, the engine tries again starting at position 1, then 2, and so on — a match anywhere in the string counts as a success.

Example

Pattern a*b against the string "aaab": the engine first tries to grab all three as for the a* part, then checks if b matches what's left — it does, so the whole thing matches. If the string were "aaa" instead (no trailing b), grabbing three as would leave nothing for b to match, so the engine backtracks to grabbing two as, then one, and so on, until it fails completely — there's no b anywhere in the string.

def is_match(text, pattern):
    if not pattern:
        return not text                          # both exhausted together: a full match

    first_matches = bool(text) and pattern[0] in (text[0], '.')  # does the first token match?

    if len(pattern) >= 2 and pattern[1] == '*':

function isMatch(text, pattern) {
  if (pattern.length === 0) return text.length === 0;  // both exhausted: a full match

  const firstMatches = text.length > 0 && (pattern[0] === text[0] || pattern[0] === '.');

  if (pattern.length >= 2 && pattern[1] === '*') {
    // zero occurrences, or one occurrence + retry
    return isMatch(text, pattern.slice(2)) ||                    // skip the starred token
           (firstMatches && isMatch(text.slice(1), pattern));     // consume one, stay on it
  }

  return firstMatches && isMatch(text.slice(1), pattern.slice(1));  // consume from both sides
}
