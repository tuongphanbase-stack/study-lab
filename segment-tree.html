Segment Tree

A tree that pre-combines array ranges so range-sum queries take O(log n) instead of O(n). Build the tree, then query any range and watch it decide which nodes it can trust directly.

How it works

A plain array can answer "what's the sum of this range?" but it has to add up every number each time, which gets slow for large ranges. A segment tree answers the same question much faster by pre-calculating sums ahead of time and storing them in a tree.

Building the tree: each leaf holds one number from the array. Every node above a leaf holds the sum of its two children. Keep combining upward until the very top node holds the sum of the whole array.

Querying a range: start at the top and work down.

  1. If a node's range sits completely inside the range you're asking about, just use its already-calculated sum. No need to go any deeper.
  2. If a node's range only partly overlaps, check its two children separately and add their results together.
  3. If a node's range doesn't overlap at all, ignore it completely.

Because most of the tree gets skipped this way, a query only ever needs to look at a small number of nodes.

Example

Array [1, 3, 5, 7]. The tree's root holds the total sum, 16. Asking for the sum of range [1, 2] (values 3 and 5) doesn't need to touch the root at all — it goes straight to the pre-calculated node covering just that range, which already holds 8.

function build(tree, arr, node, start, end):
    if start == end:                       // a single-element range: this is a leaf
        tree[node] <- arr[start]
        return
    mid <- (start + end) / 2                // split the range in half
    build(tree, arr, 2*node+1, start, mid)   // recursively build the left half
    build(tree, arr, 2*node+2, mid+1, end)   // recursively build the right half
    tree[node] <- tree[2*node+1] + tree[2*node+2]   // this node = sum of its two children

function query(tree, node, start, end, l, r):
    if r < start or end < l: return 0              // this node's range doesn't overlap [l,r]
    if l <= start and end <= r: return tree[node]    // this node's range is fully inside [l,r]

class SegmentTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n)   # 4n is enough room for any binary tree over n leaves
        self.build(arr, 0, 0, self.n - 1)

    def build(self, arr, node, start, end):
        if start == end:
            self.tree[node] = arr[start]   # single-element range: this is a leaf
            return
        mid = (start + end) // 2            # split the range in half
        self.build(arr, 2*node+1, start, mid)     # recursively build the left half
        self.build(arr, 2*node+2, mid+1, end)     # recursively build the right half
        self.tree[node] = self.tree[2*node+1] + self.tree[2*node+2]  # sum of children

    def query(self, l, r, node=0, start=0, end=None):
        if end is None:
            end = self.n - 1
        if r < start or end < l:
            return 0                        # this node's range doesn't overlap [l, r] at all
        if l <= start and end <= r:
            return self.tree[node]           # this node's range is fully inside [l, r]
        mid = (start + end) // 2            # partial overlap: split and recurse into both
        return (self.query(l, r, 2*node+1, start, mid) +
                self.query(l, r, 2*node+2, mid+1, end))
class SegmentTree {
  constructor(arr) {
    this.n = arr.length;
    this.tree = new Array(4 * this.n).fill(0);  // 4n is enough for any binary tree over n leaves
    this.build(arr, 0, 0, this.n - 1);
  }

  build(arr, node, start, end) {
    if (start === end) { this.tree[node] = arr[start]; return; }  // leaf: one element
    const mid = Math.floor((start + end) / 2);    // split the range in half
    this.build(arr, 2*node+1, start, mid);          // recursively build the left half
    this.build(arr, 2*node+2, mid+1, end);          // recursively build the right half
    this.tree[node] = this.tree[2*node+1] + this.tree[2*node+2];  // sum of children
  }

  query(l, r, node = 0, start = 0, end = this.n - 1) {
    if (r < start || end < l) return 0;                 // no overlap with [l, r] at all
    if (l <= start && end <= r) return this.tree[node];  // fully inside [l, r]
    const mid = Math.floor((start + end) / 2);          // partial overlap: split and recurse
    return this.query(l, r, 2*node+1, start, mid) +
           this.query(l, r, 2*node+2, mid+1, end);
  }
}

    int[] tree;
    int n;

    SegmentTree(int[] arr) {
        n = arr.length;
        tree = new int[4 * n];   // 4n is enough room for any binary tree over n leaves
        build(arr, 0, 0, n - 1);
    }

    void build(int[] arr, int node, int start, int end) {
        if (start == end) { tree[node] = arr[start]; return; }   // leaf: one element
        int mid = (start + end) / 2;              // split the range in half
        build(arr, 2*node+1, start, mid);            // recursively build the left half
        build(arr, 2*node+2, mid+1, end);            // recursively build the right half
        tree[node] = tree[2*node+1] + tree[2*node+2];  // sum of children
    }

    int query(int l, int r, int node, int start, int end) {
        if (r < start || end < l) return 0;              // no overlap with [l, r] at all
        if (l <= start && end <= r) return tree[node];   // fully inside [l, r]
        int mid = (start + end) / 2;                     // partial overlap: split and recurse
        return query(l, r, 2*node+1, start, mid) +
               query(l, r, 2*node+2, mid+1, end);
    }
}
