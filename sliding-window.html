Sliding Window

Two pointers sweep across a string to find the longest substring without repeating characters — expanding right, and jumping left only when it has to.

How it works

Sliding window uses two pointers, left and right, to mark the edges of a "window" over the string. Instead of checking every possible piece of the string from scratch, the window only ever moves forward — never backward.

This page solves: what's the longest stretch of the string with no repeated characters? Here's how it works:

  1. right moves forward one character at a time, growing the window.
  2. If the new character is already inside the window, left jumps forward to just past where that character last appeared — shrinking the window just enough to remove the repeat.
  3. After each step, check if the current window is the longest one seen so far.

Since left and right only ever move forward, the whole string only gets scanned once — much faster than checking every possible substring separately.

Example

String "abcabcbb": the window grows through a, b, c (length 3, no repeats). Adding the next a would repeat, so the window's left edge jumps forward past the first a. The longest repeat-free stretch found along the way is "abc", length 3.

function longestUniqueSubstring(s):
    left <- 0                          // left edge of the current window
    seen <- {}                          // character -> last index it was seen at
    best <- 0                          // longest window length found so far

    for right from 0 to length(s) - 1:               // right edge expands one step at a time
        c <- s[right]
        if c in seen and seen[c] >= left:               // duplicate found inside the window
            left <- seen[c] + 1                            // jump left past the duplicate
        seen[c] <- right                                // record this character's newest position
        best <- max(best, right - left + 1)              // update the best length seen so far

    return best

function longestUniqueSubstring(s) {
  let left = 0;               // left edge of the current window
  const seen = new Map();      // character -> last index it was seen at
  let best = 0;                // longest window length found so far

  for (let right = 0; right < s.length; right++) {   // right edge expands one step at a time
    const c = s[right];
    if (seen.has(c) && seen.get(c) >= left) {          // duplicate found inside the window
      left = seen.get(c) + 1;                            // jump left past the duplicate
    }
    seen.set(c, right);                                // record this character's newest position
    best = Math.max(best, right - left + 1);           // update the best length seen so far
  }

  return best;
}

int longestUniqueSubstring(string s) {
    int left = 0, best = 0;                    // left edge of window; best length so far
    unordered_map<char, int> seen;              // character -> last index it was seen at
