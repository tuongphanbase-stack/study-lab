Sorting Comparison

Quicksort, merge sort, and heap sort race on the same array. Watch how differently each one moves through the data to reach the same sorted result.

How it works

All three algorithms sort the same list of numbers, but each one decides what to compare or move in a different way.

  • Quicksort — pick one number as a "pivot." Move every smaller number to its left, and every larger number to its right. Then repeat that same process separately on each side. Usually fast, but a poor pivot choice on already-sorted data can slow it down a lot.
  • Merge sort — split the list in half, then keep splitting each half in half, until you're left with single numbers. Then merge pairs back together in sorted order, over and over, until it's one sorted list again. Always reliably fast, but needs extra memory to do the merging.
  • Heap sort — first arrange the whole list into a shape called a max-heap, where the largest number is always on top. Then repeatedly pull the top number off and place it at the end. Reliably fast, and unlike merge sort, doesn't need extra memory.

Watch how differently each one moves through the same numbers: quicksort jumps around in sharp partitions, merge sort works in clean, even halves, and heap sort counts down steadily from the top.

Example

Array [5, 2, 8, 1] with quicksort using the last item (1) as the pivot: nothing is smaller than 1, so it stays at the front — giving [1, 5, 2, 8] — then quicksort repeats separately on [5, 2, 8], the part to its right.

function quicksort(array, lo, hi):
    if lo >= hi: return               // fewer than 2 elements: already sorted
    pivot <- array[hi]                 // pick the last element as the pivot
    i <- lo                            // boundary: everything before i is < pivot
    for j from lo to hi - 1:            // scan the rest of the range
        if array[j] < pivot:
            swap(array[i], array[j])     // move this smaller element into the left zone
            i <- i + 1                   // grow the "smaller than pivot" zone
    swap(array[i], array[hi])          // put the pivot right after its smaller elements
    quicksort(array, lo, i - 1)        // recursively sort everything left of the pivot
    quicksort(array, i + 1, hi)        // recursively sort everything right of the pivot
def quicksort(arr, lo=0, hi=None):
    if hi is None:
        hi = len(arr) - 1     # default to sorting the whole array on first call
    if lo >= hi:
        return                 # fewer than 2 elements: already sorted

    pivot = arr[hi]            # pick the last element as the pivot
    i = lo                     # boundary: everything before i is < pivot
    for j in range(lo, hi):     # scan the rest of the range
        if arr[j] < pivot:
            arr[i], arr[j] = arr[j], arr[i]  # move this smaller element left of the boundary

    quicksort(arr, i + 1, hi)   # recursively sort everything right of the pivot
function quicksort(arr, lo = 0, hi = arr.length - 1) {
  if (lo >= hi) return;   // fewer than 2 elements: already sorted

  const pivot = arr[hi];   // pick the last element as the pivot
  let i = lo;               // boundary: everything before i is < pivot
  for (let j = lo; j < hi; j++) {   // scan the rest of the range
    if (arr[j] < pivot) {
      [arr[i], arr[j]] = [arr[j], arr[i]]; // move this smaller element left of the boundary
      i++;                                  // grow the "smaller than pivot" zone
    }
  }
  [arr[i], arr[hi]] = [arr[hi], arr[i]]; // place the pivot right after its smaller elements

  quicksort(arr, lo, i - 1);   // recursively sort everything left of the pivot
  quicksort(arr, i + 1, hi);   // recursively sort everything right of the pivot
}
static void quicksort(int[] arr, int lo, int hi) {
    if (lo >= hi) return;   // fewer than 2 elements: already sorted

    int pivot = arr[hi];     // pick the last element as the pivot
    int i = lo;               // boundary: everything before i is < pivot
    for (int j = lo; j < hi; j++) {   // scan the rest of the range
        if (arr[j] < pivot) {
            int tmp = arr[i]; arr[i] = arr[j]; arr[j] = tmp; // swap into the left zone
            i++;                                              // grow the left zone
        }
    }
    int tmp = arr[i]; arr[i] = arr[hi]; arr[hi] = tmp; // place pivot after its smaller elements

    quicksort(arr, lo, i - 1);   // recursively sort everything left of the pivot
    quicksort(arr, i + 1, hi);   // recursively sort everything right of the pivot
}
